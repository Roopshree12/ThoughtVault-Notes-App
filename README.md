#  ThoughtVault - Notes App

ThoughtVault is a modern full-stack notes application where users can create, edit, delete, search, and organize their notes.

##  Features

-  Create notes
-  Edit notes
-  Delete notes
-  Search notes
-  Change note colors
-  Dark mode
-  Light mode
-  Responsive design

##  Technologies

- React.js
- Vite
- Node.js
- Express.js
- MongoDB
- Mongoose
- REST API
- JavaScript
- CSS
